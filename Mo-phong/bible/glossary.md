# Thuật ngữ & Xưng hô

> Chính văn tiếng Trung; prompt tiếng Việt. **Đề xuất (⏳ Tác giả):** truyện bối cảnh Trung Hoa cổ nên tên riêng viết thẳng chữ Hán trong chính văn; prompt ghi Hán Việt kèm chữ Hán lần đầu mỗi đoạn — khác quy ước chữ Latin của lanh-chua-chip / goblin.

## Chuỗi cố định của máy mô phỏng (ghi nguyên văn trong prompt — AGENT.md mục 4, nguyên tắc 12)
| Lúc | 中文 |
|---|---|
| Kích hoạt (một lần duy nhất) | 【万劫模拟器，已绑定。】 |
| Lần miễn phí | 【首次模拟免费。】 |
| Bắt đầu | 【模拟开始。】 |
| Dòng log | 【<mốc thời gian>，你……】 — mốc: 第二日 / 三个月后 / 二十岁 |
| Chết | 【你死了。】 |
| Kết thúc | 【模拟结束，你可以带回其中一项：】 |
| Ba lựa chọn | 【一，修为：炼气X层。】【二，经验：……】【三，记忆：……】 |
| Giá lần sau | 【下次模拟：下品灵石一枚。】 |

Máy chỉ gọi MC là 你. Không có 宿主 / 系统 / 叮.

| Thẩm Nghiễn → Lão Chung | 钟伯 |
| Tạp dịch → đệ tử ngoại môn | 师兄 / 师姐 |
