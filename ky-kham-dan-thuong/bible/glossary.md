# Thuật ngữ

| Hán | Việt | Ghi chú |
|---|---|---|
| 宿主 | túc chủ | dòng đầu bảng |
| 阶 | bậc | 1–9, trên là 传奇 |
| 技能 | kỹ năng | có thanh tiến độ x/100 |
| 士兵 | lính | ghi số lượng + bậc |
| 士气 | sĩ khí | 0–100 |
| 人数上限 | trần quân số | mở theo cấp |
| 超凡 | siêu phàm | từ 4 阶 trở lên với dân thường |
| 兽人 / 豺狼人 | Orc / lang nhân | quân địch |
| 农奴 | nông nô | |
| 民兵 | dân binh | |

Cách gọi: thôn dân gọi MC là 欧文, lính gọi 头儿, quý tộc gọi 平民. Không 大人/老爷 với MC (hắn chưa là gì).
