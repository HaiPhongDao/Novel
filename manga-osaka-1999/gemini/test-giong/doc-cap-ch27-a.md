# Đọc cặp — mẫu và bản sinh ở cùng vị trí

Số đo chỉ chỉ ra chỗ lệch. Ở đây bày ra để đọc: chỗ nào bản sinh nói thứ mẫu không nói,
hoặc bỏ thứ mẫu có, là chỗ SI chưa dạy được.

| Vị trí | Nguyên văn mẫu | Bản sinh |
|---|---|---|
| 4% | 他看在眼里，心里还有些犯嘀咕...看的这么轻松，难道这个题材对黑川小姐没有吸引力？ | 从翻开这份名为《地狱少女》的开篇原稿开始，墙上的挂钟已经走过了将近二十分钟。 |
| 12% | 黑川碧给出了一个负责任的评价。 | 黑川碧审阅原稿的状态，与上次阅读《未麻的部屋》时完全不同。 |
| 20% | “果然。” | 黑川碧终于翻完了最后一页。她将画着黑色水手服少女的原稿收拢整齐，反扣在桌面上。 |
| 29% | 因为这里面，有一个非常严重的问题。 | 在此之前，黑川碧心里始终压着一份担忧。秋山悟花了三周时间画出这套分镜，题材却从写实的犯罪心理直接跨跳到了超自然志怪。年轻作者做出这种剧烈的风格变动，很容易丢失原有的画面压迫感。 |
| 37% | 如果是搞笑漫画，或是其他的题材，另当别论，可偏偏是这种奇幻＋恐怖的元素，要保证同样的套路下，读者不会觉得枯燥乏味，时刻保持新鲜感，对于漫画家创作能力的要求，可以说是哪怕是放在所有的漫画题材里面，都是第一梯队的！ | “但是能够接受它的读者群体，要比上一部庞大得多。”黑川碧继续道，“《未麻》属于挑剔的核心读者，阅读门槛很高。这一部完全不同，只要是在学校遭受欺凌或者在职场背负冤屈的普通人，都能立刻获得情绪上的代入。” |
| 45% | “单元剧而已，我一个人就可以画。” | “是。”秋山悟把纸杯放到桌角，“主线是阎魔爱的摆渡规则与契约代价，每一话负责处理一个独立的委托事件。” |
| 54% | 想到这里，就连黑川碧自己都忍不住有些苦笑起来——说出来的话，秋山桑都快要讨厌自己了吧？ | 真正让她感到不安的根源，是秋山悟个人的创作负荷。 |
| 62% | 一旁的秋山悟听了上句没听到下句，疑惑地看着她。 | 黑川碧从未怀疑过秋山悟展现出来的绘画天分。 |
| 70% | 再画一章？！ | “对于我来说，今天只需要从担当编辑这里得到两个明确的答复。”秋山悟看着她的眼睛，“第一，这个故事到底具不具备足够的吸引力；第二，它在连载会议上的过审概率究竟有多少。” |
| 79% | 黑川碧愣住了。 | 但这套出于健康的劝诫她在过去的几周里说过太多次，每一次都被秋山悟用确定的原稿张数直接挡了回来。 |
| 87% | “好吧，我答应你。” | “这样一来，评审席上的副主编们就不会怀疑我维系单元故事质量的能力。”秋山悟道。 |
| 95% | 这部奇幻、恐怖元素的单元剧漫画，获得第一届楳图赏，彻底奠定伊藤润二一代“恐怖漫画大师”的地位！！ | 黑川碧低头看着桌上散发着生涩墨水气味的B4纸，胸口重重起伏了一次。 |
