# Đọc cặp — mẫu và bản sinh ở cùng vị trí

Số đo chỉ chỉ ra chỗ lệch. Ở đây bày ra để đọc: chỗ nào bản sinh nói thứ mẫu không nói,
hoặc bỏ thứ mẫu có, là chỗ SI chưa dạy được.

| Vị trí | Nguyên văn mẫu | Bản sinh |
|---|---|---|
| 4% | 他看在眼里，心里还有些犯嘀咕...看的这么轻松，难道这个题材对黑川小姐没有吸引力？ | 挂在白墙上的圆形石英钟悄然走动，秒针转过了将近二十分钟。 |
| 12% | 黑川碧给出了一个负责任的评价。 | 比起上一次审阅《未麻的部屋》，Kurokawa Midori此刻的神情要舒展得多。 |
| 20% | “果然。” | Akiyama Satoru将这个微小的细节看在眼里。 |
| 29% | 因为这里面，有一个非常严重的问题。 | Akiyama Satoru迎上她的视线，将手中的空咖啡罐轻轻放在脚边。 |
| 37% | 如果是搞笑漫画，或是其他的题材，另当别论，可偏偏是这种奇幻＋恐怖的元素，要保证同样的套路下，读者不会觉得枯燥乏味，时刻保持新鲜感，对于漫画家创作能力的要求，可以说是哪怕是放在所有的漫画题材里面，都是第一梯队的！ | “平心而论，单看剧作深度与艺术上限，《地狱少女》确实比不上《未麻的部屋》。”Kurokawa Midori说。 |
| 45% | “单元剧而已，我一个人就可以画。” | “是的，您看得很准。”Akiyama Satoru说。 |
| 54% | 想到这里，就连黑川碧自己都忍不住有些苦笑起来——说出来的话，秋山桑都快要讨厌自己了吧？ | Akiyama Satoru坐在椅中，安静地等待着下文。 |
| 62% | 一旁的秋山悟听了上句没听到下句，疑惑地看着她。 | 但这毕竟是他职业生涯的第一次正式连载，起步就挑了结构最险恶的骨架。 |
| 70% | 再画一章？！ | “今天我带着原稿过来，其实只想确认两件事。”Akiyama Satoru说。 |
| 79% | 黑川碧愣住了。 | 可是类似的劝告她在过去一个月里重复过太多回，每一次都被对方直接挡了回来。 |
| 87% | “好吧，我答应你。” | 他在脑海中早已把整个编辑部的运转流程推演得一清二楚。 |
| 95% | 这部奇幻、恐怖元素的单元剧漫画，获得第一届楳图赏，彻底奠定伊藤润二一代“恐怖漫画大师”的地位！！ | 走廊尽头隐约传来主编催促分镜的呵斥声，伴随着传真机吐纸的急促噪音。 |
