# Voice Anchor — manga-tokyo-2000

```
当黑川碧一张一张计数，粗略估算了手中原稿的数量有50页左右后，终于是安耐不住露出了惊讶的神色：
“秋山桑...你也太疯狂了！居然真的画完了？！”
原先黑川碧心中预估一个月时间几乎不可能完成的任务……秋山悟最终只用了三周的时间！
而且，她仅仅只是扫了一眼，便能感觉到，这些送上来的原稿，作画质量极高，绝不是敷衍了事，相比《未麻》时期，还可以明显感觉到画功是有了一定进步的。
```
