许牧是被后颈的一阵酸痛给硌醒的。

这具身体只有二十二岁，骨头还硬，但在不到十平米的合租单间里睡了一整夜弹簧塌陷的二手折叠床，照样脖子发僵。

许牧抬手揉了揉后颈，睁眼看着头顶发黄发霉的天花板，整整愣了半分钟。

昨天下半夜两点，他还在前世那家上市游戏大厂的第七会议室里。中央空调开得像个停尸房，投影仪上打着他们组熬了十一个月、经历了四轮删档内测的二次元卡牌项目。

然后顶头上司把手里的激光笔往桌上一扔，叹了口气：“小许，大盘数据掉得太厉害，次留连百分之二十八都稳不住。董事会那边的意思……及时止损吧。”

九年策划老油条，做过数值，调过关卡，熬秃了半个脑袋，好不容易带一个大项目，一句话就被抬进了火葬场。

他散会去便利店买了包烟，点着吸了一口，胸口猛地一抽，再睁开眼，人就已经在这个同名同姓的倒霉蛋身上了。

脑子里的记忆混着昨夜残留的宿醉，乱成一锅粥。

许牧撑着床板坐起来，随手抓过扔在破塑料床头柜上的手机。

指纹解锁，屏幕亮起。

日历显示今天是他从“澜城高等造境学院”毕业的第七天。

先看短信和手机银行。

账户可用余额：412.50元。

下个月五号要交房租，八百。如果交不上，房东那个嗓门能震碎整条胡同的大婶，绝对会在十分钟内把他那两箱破烂打包扔到街对面的垃圾站。

许牧吸了口气，又点开学院的内部教务系统。

一条鲜红的系统通知挂在最显眼的位置：“您的学生认证专属造境引擎端口将于72小时后正式停用，请及时备份个人资产。”

再往下划，是毕业设计答辩的最终成绩单。

作品名称：《秋山古亭》。

指导老师综合评分：56分（未通过）。

评语只有冷冰冰的一行字：“亭台瓦片水渍反光参数偏差超过0.03%，落叶受风力物理碰撞轨迹严重失真。真实度评定：D。缺乏对物质世界的基本敬畏，建议延毕重修《环境物理学基础》。”

许牧看着那行评语，气笑了。

缺乏对物质世界的基本敬畏？

合着你们这帮做游戏的，是在招理论物理研究所的院士，还是在给测绘局培养学徒？

他关掉教务系统，顺手点开了手机里的主流求职软件。

出于九年的职业肌肉记忆，他在搜索栏里输入了“游戏策划”四个字。

搜索结果跳出来的一瞬间，许牧整个人僵住了。

第一页全是什么：

“金牌婚礼策划，月薪三千包吃住。”

“大型商场开业庆典统筹策划，要求会扎气球拱门。”

“百日宴、寿宴活动策划专员……”

许牧不信邪，删掉重输，单搜一个“策划”。

结果更离奇，甚至连殡葬一条龙的服务策划都蹦出来了。

搜索框最下面还极其贴心地弹出一行灰色小字：“未找到相关职业，您是否想搜：造境学徒、物理材质调参员、全感官渲染助理？”

许牧把手机扔在被子上，抬手使劲抹了一把脸。

行吧。

脑子里那些翻涌的记忆彻底对上了。

这个世界在大约两年前，神经潜入舱技术迎来了革命性的突破。从笨重的科研仪器，迅速迭代成了走进大街小巷的民用娱乐设备。

而在这个世界上，根本就没有所谓的“游戏设计师”或者“游戏策划”。

在这里，他们叫“造境师”。

这群人的地位高得吓人，顶尖的造境师在聚光灯下的待遇堪比一线巨星，随便发个新片区，首日就能涌入几百万玩家。

但这个行当衡量水平的唯一标准，简单粗暴得令人发指——真实度。

画面够不够真，物理碰撞够不够准，踩在雪地上的触感是不是和西伯利亚一样冷，甚至连一碗阳春面端上来的蒸汽温度，都要精确到小数点后两位。

至于玩法？数值平衡？心流设计？正向反馈循环？

对不起，不存在。

这帮造境师每天死磕的事情，就是把现实世界里的山川流水、街巷砖石，一比一用数据“搬”进潜入舱里。

在他们看来，只要做得跟真的一模一样，玩家就该感激涕零地进来跪着买单。

“神经病啊……”

许牧忍不住骂出了声。

如果玩游戏只是为了体验跟现实一模一样的东西，老子大夏天顶着太阳去爬野山不好吗？非得花钱躺进那铁棺材里去吹模拟出来的冷风？

但在骂街之前，他得先活下去。

兜里就剩四百来块，学生引擎端口三天后作废，答辩挂科连毕业证都拿不到。

他得先亲眼看看，这个世界所谓的“顶流造境”，到底是个什么成色。

知己知彼，才能决定是去给婚庆公司扎气球，还是在这片看似繁荣的蛮荒之地里，给这帮没见过世面的土著上一课。

许牧翻身下床，套上一件洗得发白的灰色连帽衫，踩着地摊拖鞋就出了门。

楼道里逼仄阴暗，空气里弥漫着老旧居民区特有的油烟味和下水道返上来的潮气。

他顺着掉皮的楼梯踩下去，推开临街那扇带纱网的铝合金防盗门。

门外就是澜城的老城区，街道狭窄，两旁的梧桐树长得歪七扭八。

而就在他租住的这栋老居民楼正下方，临街的一楼门面挂着一块有些脱色的亚克力招牌——“深蓝潜入馆”。

店招底下贴着两行反光的蓝色彩灯，大白天的也亮着，嗡嗡作响。

许牧推开玻璃门，门顶上的机械风铃叮当响了一声。

店里的温度骤降。

一股混合着高浓度消毒水、微量臭氧以及廉价桶装红烧牛肉面残汤的气味，直往鼻子里钻。

大厅里光线昏暗，靠墙整整齐齐码放着两排深灰色的全功能潜入舱。造型像一个个立起来的大号胶囊，舱盖上的呼吸灯正在幽幽地闪着蓝光，显示里面全都有人。

柜台后面，一个胡子拉碴的中年男人正低头吸溜着泡面。

正是老板老周。

老周身上套着件洗得领口卷边的黑背心，听见风铃响，头也不抬：“单人普通舱二十一小时，双人联机三十五，充一百送二十。自带营养液减五块，押金一百。”

“周叔，是我。”许牧走到柜台前，屈起手指敲了敲柜面。

老周嚼着泡面抬起头，眯着眼打量了他两秒，乐了：“哟，小许啊。怎么着，今儿不用在破电脑前调你那破烂亭子了？毕业答辩过了没啊？领了证赶紧请周叔抽包好的，不枉我平时让你白蹭那两台旧舱跑测试。”

“挂了。”许牧神色平静。

老周刚夹起的一筷子泡面停在半空，愣了一下，随即干笑两声：“嗨，挂了就挂了呗。早跟你说了，造境师那是金领行业，是祖师爷赏饭吃。你那手艺，调个光线都发灰，非得硬挤那独木桥干啥。隔壁老张儿子，花三万块去市里报了个高精度材质培训班，上个月照样被大厂给退回来了。”

老周放下泡面叉子，扯了张劣质抽纸抹抹嘴：“不过你也别愁，你那双手画图还行，去建材城搞个室内装潢效果图，一个月也能挣个三四千，饿不死。”

许牧没接装潢的话茬，直接掏出手机：“周叔，开台机器。”

“开机器？你还测试啊？你那学生端口不是快封了么？”

“不测我的。”许牧指了指柜台上方那块最大的液晶光屏，“给我开一台能跑商业大作的高配舱，我要看《千灯巷》。”

老周正准备去摸烟盒的手猛地顿住。

他瞪大眼睛看着许牧，像是看着个突然发癔症的穷亲戚。

“你看《千灯巷》？小许，你没睡醒呢？”

老周咂了咂嘴，指着光屏上的海报：“那是陆志大师团队上个月刚上线的新作！官方评级二星境，真实度高达91.4%！拿到东陆造境展银奖的大热商业作品！你上他们服务器玩一小时，平台抽成加境域门票，再算上我这的高配舱电费磨损，一小时四十五块！概不打折！”

老周敲了敲桌子：“四十五块！你小子平时兜里掏不出二十块钱，今天吃错药了？”

“四十五就四十五。”

许牧把手机屏幕倒扣在收银台的扫码枪上。

“哔”的一声轻响。

扣款成功短信瞬间弹了出来。

可用余额瞬间缩水成了367.50元。

老周看着收银机屏幕上跳出来的到账提示，眼皮跳了跳。

他深深看了许牧一眼，没再废话，把手里的烟盒往桌上一扔，从柜台下面摸出一张消过毒的神经感应贴片，连同一把黄铜小钥匙递了过去。

“七号舱，最里面那台。散热风扇刚清过灰，性能最好。”

老周叹了口气，摇摇头：“行吧，有钱不赚王八蛋。不过周叔劝你一句，看完别受太大打击。人家那是十几个专业建模师加物理引擎大师干了半年的心血，里头一砖一瓦都跟真的一样。你看了，除了觉得自己是个废物，没别的好处。”

“那我倒要看看，有多真。”

许牧接过感应贴片，扯了扯嘴角，转身朝深处走去。

七号舱在最靠墙的角落。

这是一台半新不旧的“深航-4型”通用潜入舱，外壳是磨砂质感的银灰色工程塑料，侧面有些许刮痕，但维护得还算干净。

许牧抬手按下外壳上的机械锁扣。

“哧——”

伴随着一声轻微的液压泄气声，椭圆形的舱盖缓缓向上滑开。

里面的构造极其紧凑。

一张符合人体工学的黑色凝胶躺椅，两侧是带有束缚带的安全护翼，头枕位置由微凉的人造皮革包裹，散发着淡淡的酒精气味。上方悬垂着两根细长的神经信号接入探头，泛着冷冽的金属光泽。

许牧站在舱边，看着这个在他前世只存在于科幻电影和设定集里的东西。

真实度91.4%的顶流大作。

没有策划的世界。

他倒要亲自验一验，这个世界的玩家，每天花大把的钞票和时间，到底都在这棺材盒子里享受些什么玩意儿。

许牧撕开手里的贴片包装，将两片薄如蝉翼的导电贴分别按在自己的双侧太阳穴和耳后风池穴上。

随后，他弯下腰，抬腿跨进了潜入舱。

凝胶坐垫微微下沉，迅速包裹住他的身体，冰凉而柔软。

后脑勺陷进特制的头枕凹槽中，金属探头感应到贴片的位置，轻轻吸附了上来，带来一阵轻微的酥麻感。

视野正上方，舱门内侧的微型投影仪投射出一道淡蓝色的倒计时光幕：

【用户神经元连接已就绪。】

【已锁定体验境域：《千灯巷》（商业版）。】

【系统自检完成，舱门即将闭合，请保持呼吸平稳，不要强行抗拒感官剥离……】

耳边传来机械绞盘转动的低沉嗡鸣。

沉重的复合材料舱盖开始自上而下缓缓合拢。

潜入馆里昏暗的蓝光、消毒水的味道、老周吸溜泡面的动静，都在那条逐渐缩小的缝隙中被迅速切断。

光线彻底消失。

“咔哒。”

锁扣闭合的一瞬间，黑暗如潮水般将他吞没。
