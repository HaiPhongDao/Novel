## Chuỗi cố định của Diễn Sinh Lục (ghi nguyên văn trong prompt — AGENT.md mục 4, nguyên tắc 12)
| Lúc | 中文 |
|---|---|
| Kích hoạt (một lần duy nhất) | 【演生录，已认主。】 |
| Lần miễn phí | 【首演免费。】 |
| Bắt đầu | 【演生开始。】 |
| Dòng log | 【<mốc thời gian>，你……】 — mốc: 第二日 / 三个月后 / 二十岁 |
| Chết | 【此生已终。】 |
| Kết thúc | 【演生结束，可带回其中一项：】 |
| Ba lựa chọn | 【一，功力：X品。】【二，招式：……】【三，记忆：……】 |
| Giá lần sau | 【下次演生：需一顿饱饭。】 |
| Chưa ăn đủ | 【气血不足，演生未启。】 |

Máy chỉ gọi MC là 你. Không có 宿主 / 系统 / 叮.

## Xưng hô (CỐ ĐỊNH)
| Người nói → người nghe | Cách gọi |
|---|---|
| Tạp vụ → Tiền Lục | 钱管事 |
| Tiền Lục → Hàn Yến | 韩晏 / 小子 / 扫地的 |
| Tiểu Đậu Tử ↔ Hàn Yến | 晏哥 ↔ 豆子 |
| Hàn Yến → Phạm bà | 范婆婆 |
| Phạm bà → Hàn Yến | 小韩 |
| Tạp vụ → đệ tử ngoại viện | 师兄 |
| Mọi người → Nghiêm giáo đầu | 严教头 |
