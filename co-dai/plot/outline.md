# Dàn ý

> Đơn vị là **đoạn** (~2000 字). Hai cột cuối để rà soát nhịp (`../../chung/xay-dung-truyen.md` mục 5–7):
> - **Trạng thái đổi**: mục tiêu / rủi ro / thông tin / quan hệ / tài nguyên / thân phận / lập trường cảm xúc — mỗi đoạn ít nhất một.
> - **Loại**: xung đột–sướng / gắn kết / xây thế lực / phong thổ / leo thang ngầm.
> - **Dừng**: kiểu chỗ dừng giữa mạch (bảng mục 7).
